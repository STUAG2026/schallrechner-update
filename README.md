# STUAG Schallrechner – Installer und Updates

Dieses Repository enthält ausschließlich die **Installer und Update-Pakete** des Programms
„STUAG – Schallrechner Luftwärmepumpe“ der B69 STUAG Bauprojekte GmbH. Es enthält keinen Quellcode und keine Daten.

## Installation
1. Unter [Releases](../../releases/latest) die Datei `StuagSchallrechner-win-Setup.exe` herunterladen.
2. Ausführen – die Installation erfolgt für den angemeldeten Windows-Benutzer, ohne Administratorrechte.
   Warnt Windows SmartScreen, „Weitere Informationen › Trotzdem ausführen“ wählen.
3. Das Programm prüft danach selbst auf Updates.

Voraussetzung: Windows 10/11 (64 Bit).

## Hinweis
Planungshilfe – kein Ersatz für ein Schallgutachten. Die Gerätedaten liegen in der Verantwortung der Hersteller.
